FAQ

Pertanyaan seputar Convert Gambar

Format apa saja yang didukung?

Tool ini mendukung konversi antar format JPG, PNG, dan WebP, baik sebagai file sumber maupun target.

Apakah kualitas gambar berkurang saat convert?

Untuk target JPG dan WebP, ada slider kualitas yang bisa diatur. Untuk PNG, konversi bersifat lossless sehingga kualitas visual tetap terjaga.

Apakah gambar saya diunggah ke server?

Tidak, konversi memakai Canvas API bawaan browser sehingga gambar tidak pernah meninggalkan perangkatmu.
