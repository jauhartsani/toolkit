FAQ

Frequently Asked Questions about the QR Generator

Does the QR code I create last forever?

Yes, the QR codes generated are static (the data is embedded directly inside them), so there is no expiry date and no connection to ToolkitMe servers is needed to read them.

Is the data I enter sent to a server?

No, the QR code is generated entirely in your browser — text or WiFi data is never sent to any ToolkitMe server.

What format is the download?

The QR code is downloaded as a high-resolution PNG file, ready to print or use in designs.

Can I make a QR code for WiFi?

Yes, select the WiFi tab, enter the network name and password, and the generated QR code can be scanned directly to connect to that WiFi.
