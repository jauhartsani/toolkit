FAQ

Frequently Asked Questions about Merge PDF

Is there a limit to how many PDF files I can merge?

There is no hard limit set by ToolkitMe. The only limit is your device browser’s available memory for very large or very numerous files.

Can I control the page order?

Yes. Use the up/down arrow buttons on each file in the list to set the order before merging.

Are my PDF files uploaded to a server?

No. The merging process runs entirely in your browser using pdf-lib — files are never sent to any ToolkitMe server.

What if one of the PDFs is password-protected?

Password-protected PDFs currently cannot be processed. Unlock the PDF first before merging it.
