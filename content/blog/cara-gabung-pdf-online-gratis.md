Situasi ini pasti familiar: hasil scan dokumen jadi beberapa file PDF terpisah (satu file per halaman), atau kamu perlu menggabungkan CV, transkrip, dan sertifikat jadi satu file untuk dikirim sebagai lampiran lamaran kerja. Daripada kirim lima file terpisah yang gampang tercecer, lebih rapi kalau digabung jadi satu PDF saja.

## Kenapa harus digabung, bukan sekadar dikirim terpisah

Banyak formulir pendaftaran online atau sistem HRD sekarang mensyaratkan "satu file PDF berisi semua dokumen pendukung" — bukan karena teknis semata, tapi supaya reviewer tidak perlu buka-tutup banyak file satu-satu. File PDF gabungan juga lebih gampang di-print sekaligus, lebih rapi disimpan di folder, dan urutan halamannya bisa diatur sesuai kebutuhan (misalnya surat lamaran dulu, baru CV, baru sertifikat).

## Cara gabung PDF online

1. **Buka [Gabung PDF ToolkitMe](/pdf/merge.html).** Tidak perlu install aplikasi tambahan atau daftar akun.
2. **Seret semua file PDF yang mau digabung** ke kotak upload, atau klik untuk memilih beberapa file sekaligus dari perangkatmu.
3. **Atur urutan halamannya.** Setiap file yang sudah masuk akan tampil sebagai daftar — pakai tombol panah naik/turun untuk mengubah urutan penggabungan sesuai yang kamu mau.
4. **Klik "Gabungkan PDF".** Prosesnya berjalan langsung di browser, biasanya hanya butuh beberapa detik tergantung ukuran total filenya.
5. **File hasil gabungan otomatis terunduh** sebagai satu file PDF utuh, siap dikirim atau disimpan.

## Berapa banyak file yang bisa digabung sekaligus

Tidak ada batas jumlah file yang dipatok secara sengaja — kamu bisa gabungkan dua file atau dua puluh file sekaligus. Batasan praktisnya hanya kemampuan memori browser di perangkatmu kalau total ukuran filenya sangat besar (ratusan MB). Untuk kebutuhan sehari-hari seperti gabung dokumen lamaran kerja, hasil scan KTP/ijazah, atau laporan kerja per-bab, ini jauh lebih dari cukup.

## Kalau salah satu file PDF-nya terkunci password

Tool ini saat ini belum bisa memproses PDF yang dilindungi password. Kalau salah satu file kamu terkunci, buka dulu kuncinya (biasanya lewat aplikasi PDF reader yang kamu pakai untuk membuka file tersebut) sebelum diupload untuk digabung.

## Apakah file PDF saya aman?

Sama seperti tools lain di ToolkitMe, proses penggabungan PDF berjalan 100% di browser kamu sendiri lewat teknologi bernama pdf-lib — bukan diproses di server. Artinya dokumen yang mungkin berisi data pribadi (KTP, ijazah, kontrak) tidak pernah diunggah atau disimpan di mana pun selain di perangkatmu sendiri.

Selain gabung PDF, ToolkitMe juga punya [compress JPG](/compress/compress-jpg.html) kalau kamu perlu mengecilkan ukuran foto/scan sebelum dijadikan PDF, dan [QR code generator](/qr/index.html) kalau butuh menambahkan kode QR ke dokumen yang kamu buat.
